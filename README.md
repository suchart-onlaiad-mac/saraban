# สารบรรณง่ายนิดเดียว

สื่อการเรียนรู้ระเบียบงานสารบรรณ เตรียมสอบตำรวจ (ภาคสารบรรณ) · บทละ 3 ชั้น + เกมด่านปลดล็อก · เปิดได้ทุกอุปกรณ์

- บท 0–3: 📨 หนังสือหนึ่งฉบับ · ✉️ ภายนอก ภายใน ประทับตรา · 📢 สั่งการ ประกาศ และหลักฐาน · ⚡ ด่วน เวียน สำเนา
- บท 4–7: 📬 รับและส่ง · 🗄️ เก็บ ยืม ทำลาย · 🦅 ตรา แบบพิมพ์ ซอง · 💻 สารบรรณอิเล็กทรอนิกส์ (ลิงก์ไปแอปไอทีง่ายนิดเดียว)
- บท 8: 🏆 เกมรวม
- เนื้อหาคัดจากระเบียบสำนักนายกรัฐมนตรีว่าด้วยงานสารบรรณ พ.ศ. 2526 และที่แก้ไขเพิ่มเติม (ถึงฉบับที่ 4 พ.ศ. 2564) · ไม่รวมเรื่องชั้นความลับ
